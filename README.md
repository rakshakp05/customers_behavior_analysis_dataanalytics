Customer Shopping Behavior Analysis

A complete data analytics project focused on analyzing customer shopping behavior using Python, PostgreSQL, SQL, and Power BI. The project covers the complete analytics workflow—from loading and cleaning raw data to exploratory analysis, SQL-based business insights, dashboard creation, and reporting.

📌 Project Overview

This project analyzes customer shopping behavior to uncover patterns in purchasing, customer segments, product performance, discounts, subscriptions, shipping preferences, and revenue.

The workflow includes:

Python → EDA & Data Cleaning → PostgreSQL → SQL Analysis → Power BI Dashboard → Report & Presentation

🔄 Project Workflow
1. Data Loading

The dataset is loaded into Python using Pandas.

import pandas as pd

df = pd.read_csv('customer_shopping_behavior.csv', sep='\t')
2. Exploratory Data Analysis

The dataset is explored to understand:

Number of rows and columns
Data types
Missing values
Duplicate records
Statistical information
Categorical and numerical variables
Customer purchasing patterns
3. Data Cleaning

The data is prepared for analysis by:

Cleaning column names
Handling missing values
Checking duplicates
Correcting data types
Creating useful analytical fields such as customer segments and age groups

Example:

df.columns = (
    df.columns
    .str.lower()
    .str.strip()
    .str.replace(' ', '_')
)
4. PostgreSQL

The cleaned dataset is loaded into PostgreSQL.

Database:

customer_behavior

Table:

customer

Python and SQLAlchemy are used to transfer the DataFrame into PostgreSQL.

5. SQL Analysis

SQL queries are used to answer important business questions, including:

What is the total revenue generated by male vs. female customers?
Which customers used discounts but spent more than the average purchase amount?
What are the products with the highest average review ratings?
How do Standard and Express shipping customers compare in average purchase amount?
Do subscribed customers spend more?
Which products have the highest discount rates?
How many customers are New, Returning, and Loyal?
What are the most purchased products within each category?
Are repeat buyers also likely to subscribe?
What is the revenue contribution of each customer group?

⚙️ How to Run
1. Clone the repository
git clone <repository-url>
cd customer-shopping-behavior
2. Install Python dependencies
pip install pandas matplotlib sqlalchemy psycopg2-binary jupyter
3. Start Jupyter Notebook
jupyter notebook

Open the analysis notebook and run the cells sequentially.

4. Configure PostgreSQL

Create the database:

customer_behavior

Make sure PostgreSQL is running on:

localhost:5432

Update the PostgreSQL username and password in the notebook.

5. Load the data

Run the PostgreSQL connection and to_sql() section to create the customer table.

6. Run SQL Analysis

Execute the SQL queries in PostgreSQL/pgAdmin.

7. Open Power BI

Connect Power BI to:

Server: localhost:5432
Database: customer_behavior
Table: customer

Then refresh the dashboard.
